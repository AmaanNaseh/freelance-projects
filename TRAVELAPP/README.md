## Setup Guide

Make sure to install <a href="https://docs.flutter.dev/get-started/install">Flutter</a>, <a href="https://code.visualstudio.com/download">VS Code</a> and Flutter Extension (from Dart Code in VS Code) in your system

1. Clone the repository

```bash
git clone https://github.com/<username>/travelapp.git
```

2. Navigate to project folder

```bash
cd Project
```

3. Open terminal and run the app

```bash
flutter run
```

(OPTIONAL) To build and use as APK, run following command

```bash
flutter build apk --release
```
